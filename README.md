# Silent Films

Turns Minecraft into a silent film.

# <span style="color:#E03E2D;">COMPATIBLE WITH SIMPLE VOICE CHAT!
</span>
Download an additional voice to text model ingame and convert your words into intertitles.
Currently does NOT support voice activation, sorry! Coming later! 
Please use **Push To Talk** for now!

## Current Features

*   Monochrome film filter
*   Film grain, flicker, vignette, and letterbox effects

![image](https://media.forgecdn.net/attachments/description/1634093/description_14147a84-3f75-47eb-8dab-f57ef761c625.gif)

*   Iris transitions for teleportation and sleeping. Multiplayer compatiblle.

![image](https://media.forgecdn.net/attachments/description/1634093/description_4f897da5-260f-4e5c-a870-c8dbd75373ab.gif)

![image](https://media.forgecdn.net/attachments/description/1634093/description_c7c1cb9f-81b0-4e61-b754-7f17ecdba5ab.gif)

*   **Local area** multiplayer chat **intertitles**

![image](https://media.forgecdn.net/attachments/description/1634093/description_77d8adf4-018a-4725-a42f-310e804916e4.gif)

*   Custom settings menu with **default keybind K**, Mod Menu compatible.

*   Soundtrack that accompanies your gameplay. Customizable!
